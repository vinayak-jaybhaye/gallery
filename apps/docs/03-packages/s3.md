# @gallery/s3

**Path:** `packages/s3`

## Responsibilities

Thin wrapper around `@aws-sdk/client-s3` with a single factory tuned for LocalStack and AWS.

## `createS3Client(config)`

```typescript
import { createS3Client, PutObjectCommand, getSignedUrl } from "@gallery/s3";

const client = createS3Client({
  region: process.env.AWS_REGION!,
  accessKeyId: process.env.AWS_ACCESS_KEY_ID!,
  secretAccessKey: process.env.AWS_SECRET_ACCESS_KEY!,
  endpoint: process.env.S3_ENDPOINT, // optional
});
```

### Behavior (`packages/s3/src/index.ts`)

| Option | Effect |
|--------|--------|
| `endpoint` set | `forcePathStyle: true` (required for LocalStack) |
| Always | `requestChecksumCalculation: "WHEN_REQUIRED"` — avoids extra checksum query params on presigned PUT URLs that break LocalStack browser uploads |

Re-exports all `@aws-sdk/client-s3` commands and `getSignedUrl` from `@aws-sdk/s3-request-presigner`.

## Consumers

- **API** — Presigned PUT/part URLs, multipart create/complete/abort/list, head object, delete objects on hard trash
- **Media worker** — `getObject` / `uploadObject` helpers in `apps/media-worker/src/lib/s3.ts` wrapping the shared client

## Object key layout

Per media item (see [data model](../07-data-model/schema.md#s3-object-keys)):

```text
users/{ownerId}/{mediaId}/original     # raw upload
users/{ownerId}/{mediaId}/master.jpg # or master.mp4 after processing
users/{ownerId}/{mediaId}/thumbnail.jpg
```
